# Customer Shopping Behavior Analysis

A data analytics project that explores customer purchasing patterns, product preferences, spending behavior, and subscription trends using Python, PostgreSQL, and Power BI.

## Project Overview

This project analyzes **3,900 purchase records** across different product categories. The objective is to turn transactional data into useful business insights about customer segments, revenue, product performance, discounts, shipping preferences, and subscription behavior.

The workflow covers data preparation and exploratory data analysis in Python, business analysis in PostgreSQL, and interactive visualization in Power BI.

## Dataset

- **Records:** 3,900
- **Columns:** 18
- **Missing data:** 37 values in the `review_rating` column
- **Main data areas:**
  - Customer demographics: age, gender, location, and subscription status
  - Purchase details: item, category, purchase amount, season, size, and color
  - Shopping behavior: discount and promo-code usage, previous purchases, purchase frequency, review rating, and shipping type

## Project Workflow

### 1. Data Loading and Exploration — Python

- Loaded the dataset using Pandas.
- Inspected the data structure with `df.info()`.
- Reviewed descriptive statistics with `df.describe()`.
- Checked the dataset for missing values and inconsistencies.

### 2. Data Cleaning and Preparation — Python

- Imputed the 37 missing values in `review_rating` using the median rating for the corresponding product category.
- Standardized column names to `snake_case`.
- Created an `age_group` feature by grouping customer ages.
- Created a `purchase_frequency_days` feature from purchase data.
- Checked whether `discount_applied` and `promo_code_used` contained redundant information and dropped `promo_code_used`.
- Loaded the cleaned DataFrame into PostgreSQL for further analysis.

### 3. Business Analysis — PostgreSQL

SQL queries were used to investigate these business questions:

1. **Revenue by gender:** Compare total revenue generated by male and female customers.
2. **High-spending discount users:** Find customers who used discounts but spent more than the average purchase amount.
3. **Top five products by rating:** Identify products with the highest average review ratings.
4. **Shipping type comparison:** Compare average purchase amounts across shipping types.
5. **Subscribers vs. non-subscribers:** Compare average spending and total revenue by subscription status.
6. **Discount-dependent products:** Find five products with the highest percentage of discounted purchases.
7. **Customer segmentation:** Classify customers as New, Returning, or Loyal based on purchase history.
8. **Top products per category:** Identify the three most purchased products in each category.
9. **Repeat buyers and subscriptions:** Check subscription status among customers with more than five purchases.
10. **Revenue by age group:** Calculate the revenue contribution of each age group.

### 4. Dashboard — Power BI

An interactive Power BI dashboard was created to present key metrics and customer trends.

The dashboard includes:

- Number of customers
- Average purchase amount
- Average review rating
- Customer subscription status
- Revenue by product category
- Sales by product category
- Revenue by age group
- Sales by age group

It also includes slicers for subscription status, gender, category, and shipping type.

## Business Recommendations

Based on the analysis, the project report recommends:

- **Boost subscriptions:** Promote exclusive benefits to encourage subscription.
- **Build customer loyalty:** Reward repeat buyers and encourage movement into the Loyal segment.
- **Review discount policy:** Balance the sales impact of discounts with margin control.
- **Improve product positioning:** Highlight top-rated and best-selling products in marketing campaigns.
- **Use targeted marketing:** Focus campaigns on high-revenue age groups and express-shipping users.

## How to Run

### Prerequisites

- Python 3
- Jupyter Notebook
- PostgreSQL
- Power BI Desktop

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd Customer-Shopping-Behavior-Analysis
```

### 2. Install Python dependencies

```bash
pip install pandas numpy jupyter
```

Install any additional libraries used in your notebook, if applicable.

### 3. Run the Python analysis

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open the project notebook and run the cells to load, explore, and clean the dataset.

### 4. Run the SQL analysis

- Start PostgreSQL and create a database.
- Import the cleaned dataset into a table.
- Open and execute the SQL queries in the `sql/` folder.

Update database connection details in your Python script or notebook to match your local PostgreSQL setup.

### 5. Open the Power BI dashboard

Open the `.pbix` file in Power BI Desktop. If prompted, update the data source connection and refresh the data.
